nl2sparql

Overview

A question, a Turtle ontology, and optional context go in. One SPARQL query comes out. The model is a generator. Nothing here is trained on query pairs.

On this page
  1. The pieces
  2. One call
  3. Install

The public entry is generate. It loads a compact vocabulary, asks a model for a draft, walks a fixed list of stages, and checks that the result parses. The stages are the place later techniques plug in. Today each of them returns the draft unchanged.

The pieces

GenerateThe command, generate, and the prompt that lists prefixes, classes, and properties. VocabularyClasses, properties, and prefixes read from a Turtle file, capped for the prompt. StagesGuardrails, query guided, context guided, and chase and backchase. Hooks only, for now. ValidationExtract the query, lift modifiers out of WHERE, parse, and repair once. ModelsA local Ollama model by default, or an OpenAI-compatible API.

One call

  1. load_vocabulary reads the Turtle file.
  2. build_prompt lists prefixes, classes, properties, context, and examples.
  3. complete asks the model for one query.
  4. prepare_draft extracts the query and lifts solution modifiers.
  5. apply_stages walks guardrails, query guided, context guided, then chase and backchase.
  6. parse_error checks the query. On failure, one repair call runs, then the same stages and the same check.

The return value is a dict with sparql, model, and provider.

Install

git clone https://github.com/lamng3/nl2sparql.git
cd nl2sparql
pip install -e .

Python 3.11 or newer. Dependencies are rdflib and httpx. Tests use the dev extra: pip install -e ".[dev]", then pytest.
