    Python and CLI

    Ask, plan, build few-shot examples, run benchmarks, and serve the Text2SPARQL challenge API.

    On this page
    1. Command line
    2. Python
    3. Models

    Command line

    hermes ask --graph corporate "Who is Heinrich Hoch's manager?" --calls 3 --rows 50000
hermes ask --files data.ttl --ontology onto.ttl "..."
hermes plan --graph corporate --file query.rq
hermes fewshot build --graph corporate --count 30
hermes data fetch ck26 db26
hermes run configs/ck26/hermes.yaml
hermes sweep configs/sweeps/hermes.yaml
hermes report
hermes serve --config configs/ck26/hermes.yaml     # the Text2SPARQL challenge API

    Python

    from hermes import Budget, Hermes, KnowledgeGraph
from hermes import planner

answer = Hermes(kg, budget=Budget(llm_calls=3)).ask(question)
optimized = planner.plan(sparql, kg)
result = planner.PlanExecutor(kg)(optimized.query)

    Models

    Ollama by default (HERMES_OLLAMA_MODEL), or HERMES_LLM_PROVIDER = openai, anthropic, together, huggingface, vllm or modal with the provider's key. Completions can be cached on disk so runs replay (llm.py).
